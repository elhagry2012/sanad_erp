# سند للأعمال - نظام ERP لتكاليف المطاعم

## التشغيل
1. `pip install -r requirements.txt`
2. `streamlit run app.py`
3. ادخل بحساب المدير العام (momar). غيّر كلمة المرور فورًا من صفحة «حسابي».

## التحديث بدون فقدان البيانات
- قاعدة البيانات الفعلية هي الملف `database/sanad.db` وهو غير مضمَّن في أي تحديث.
- عند التحديث استبدل ملفات الكود فقط واترك `database/sanad.db` و`backups/` كما هما.
- عند كل تشغيل يضيف النظام تلقائيًا أي أعمدة أو جداول ناقصة (ترقية آمنة لا تحذف شيئًا).
- نسخة احتياطية يومية تلقائية في `backups/` (آخر 30 نسخة).

## الصلاحيات
- momar: كل شيء + «إنتاجية الموظفين» + «إدارة الحسابات والإعدادات».
- باقي الحسابات (partner): كل بيانات المشتريات والمخازن والتقارير، بدون صفحتي المدير.
- كل عملية إضافة/تعديل/حذف تُسجَّل باسم المستخدم في جدول audit_log.

## بيانات تجريبية (اختياري)
`python -m database.seed`

## الخزينة والفواتير الضريبية (تحديث)
- شاشة الدخول فيها قائمة المطاعم. المدير العام يدخل بدون مطعم فيرى نظرة عامة مجمّعة ومفصّلة لكل مطعم.
- الخزينة لكل مطعم: الوارد من مبيعات الكاشير (النقدية) والمنصرف من سداد الفواتير والدفعات والمصروفات، مع قيود يدوية.
- فاتورة الشراء: حساب لحظي لكل سطر وللإجمالي، إنشاء صنف جديد من داخل الفاتورة، ضريبة قيمة مضافة وضريبة خصم تحت حساب الدفعات المقدمة، وصورة الفاتورة.
- صور الفواتير تُحفظ في مجلد `invoice_images/` بجانب المشروع. انسخه مع `backups/` عند أي نقل أو نسخ احتياطي.
- ترقية القاعدة تتم تلقائيًا (أعمدة وجداول جديدة فقط)، ولا يُحذف أي سجل موجود.

## النسخة الأخيرة: ما الجديد
- صلاحيات دقيقة لكل مستخدم (وحدات: عرض/تعديل، ومطاعم محددة) تُفرض في طبقة الخدمات، وكل رفض يُسجَّل.
- جلسات مخزنة بالخادم (خمول وعمر أقصى وإنهاء من المدير)، وتشفير argon2id (أو PBKDF2 600 ألف دورة)، وسياسة كلمات مرور.
- مخازن متعددة وأذون تحويل (قيد الاعتماد/معتمد/ملغي) وجرد لكل مخزن وتقرير مجمّع.
- وحدات شراء واستهلاك بمعاملات تحويل ومتوسط تكلفة مرجح لكل وحدة استهلاك، وتفجير الوصفات.
- الخزينة النقدية وحساب البنك منفصلان، وطريقة الدفع (نقدي/بنك/آجل) في المبيعات والمشتريات والمصروفات.
- قنوات الطلب، الهدر والتالف، هندسة القائمة، وتنبيهات المخزون حسب معدل الاستهلاك.
- الإعدادات من متغيرات البيئة (`.env.example`)، وملف `DEPLOY.md` للنشر السحابي.
